# Uso da IA Gemini no Projeto

## Finalidade

Durante o planejamento e a estruturação da entrega final de Bootcamp I, a inteligência artificial Gemini foi utilizada como ferramenta de apoio técnico. As sugestões recebidas foram analisadas antes da aplicação, respeitando o contexto de um projeto individual.

## Interações registradas

### Planejamento da entrega final

**Solicitação enviada ao Gemini:**

> Compartilho as instruções do Desafio de Entrega Final: Implantação PortfolioHUB + IA GEMINI. Preciso estruturar as 6 seções solicitadas: Planejamento, Configuração e Integração com GitHub, Gestão de Usuários e Segurança, Compartilhamento e Controle de Acesso, Finalização/Testes e Apresentação Final.

**Resultado aproveitado:** organização da documentação do projeto, definição de boas práticas de versionamento, proposta de melhoria do README e orientação sobre publicação no GitHub Pages.

### Revisão de segurança e finalização

**Solicitação enviada ao Gemini:**

> Meu PortfolioHUB já possui repositório público e GitHub Pages funcionando. Não quero criar outro projeto nem usar Vercel ou Render. Crie um plano de implantação em etapas para a entrega final de Bootcamp I, cobrindo: integração com GitHub, segurança individual, controle de acesso, testes e documentação. Indique apenas ações realistas para um projeto individual.

**Resultado aproveitado:** checklist de segurança, revisão do `.gitignore`, testes manuais, validação de links, organização de commits e recomendação de criar uma tag ou release para marcar a versão final.

## Aplicações no PortfolioHUB

- **Planejamento:** estruturação das etapas de implantação e entrega.
- **Segurança:** orientação para não versionar credenciais, tokens, senhas ou arquivos `.env` com dados reais.
- **Documentação:** apoio para tornar o README e os documentos do projeto claros para a banca avaliadora.
- **Validação:** definição de uma checklist para verificar links, navegação e publicação no GitHub Pages.
- **Governança:** recomendação de mensagens de commit claras e de uma tag de entrega.

## Uso responsável

O Gemini não recebeu credenciais, dados pessoais sensíveis, tokens ou chaves de API. As respostas da ferramenta não foram adotadas automaticamente: a proprietária verificou quais sugestões eram compatíveis com o repositório e com os requisitos da atividade.
